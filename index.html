Suara Kita,Musyawarah Kita.

Setiap pengalaman mahasiswa layak didengar. Sampaikan keluhan, kebutuhan, dan usulan secara jujur serta santun sebagai bahan musyawarah Kelompok 5 Pancasila.

Tugas UAS Pancasila // 1INFD // Desember 2026

Musyawarah // Sila ke-4 Pancasila

Pengalaman mahasiswa adalah bahan pertimbangan. Sampaikan dengan objektif, hormati perbedaan, dan jaga etika musyawarah.

Empat doktrin konsensus

Pengalaman dicatat, dibahas bersama, lalu dirangkum menjadi rekomendasi yang beretika.

[01 // PREMIS]SEC.01

Mengangkat yang terpendam

Keresahan tentang pelayanan, akademik, dan fasilitas perlu disampaikan dengan lugas agar dapat dipertimbangkan bersama.

DOK. ID // DTR-01-PRM
[02 // PROTOKOL]SEC.02

Data identitas tidak diminta

Kami tidak meminta nama, NIM, atau email. Tuliskan permasalahan dan usulan tanpa menyebut nama individu.

DOK. ID // DTR-02-ETK
[03 // DELIBERASI]SEC.03

Musyawarah mufakat

Pendapat disusun melalui musyawarah dan permusyawaratan yang berlandaskan Sila ke-4 Pancasila.

DOK. ID // DTR-03-MSY
[04 // RESOLUSI]SEC.04

Menjadi rekomendasi

Aspirasi dapat dirangkum menjadi rekomendasi yang direncanakan disampaikan melalui Advomiba.

DOK. ID // DTR-04-RKM

Korespondensi musyawarah // Catatan proses

Dari pengalaman menjadi bahan pertimbangan

Aspirasi dikumpulkan pada 3-5 Desember, dibahas pada 6-7 Desember, dirangkum menjadi rekomendasi pada 8-12 Desember, dan dipresentasikan pada 15 Desember.
